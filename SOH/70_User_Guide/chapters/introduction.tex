\section{Module Overview}

\begin{figure}[H]
	\centering
	\includegraphics[width=0.7\textwidth]{images/layers}
	\caption{Layers}
	\label{fig:Layers}
\end{figure}

The SUM\_SOH is a software module in the application layer of the standardized architecture of AUTOSAR.

SUM\_SOH implements the following functionalities:

\begin{itemize}
	\item Reset reliability monitor.
	\item Memory Status reliability monitor.
	\item Platform reliability monitor.
	\item Communication reliability monitor.
	\item Watchdog Manager reliability monitor.
	\item Provide monitored events data via DIDs 0xF08F to 0xF093 (DID 0xF094 is implemented by ERRH).
	\item Clear monitored events logs via RID.
\end{itemize}
