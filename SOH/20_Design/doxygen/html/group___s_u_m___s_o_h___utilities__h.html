◆ SOH_MonitorShutDownTimer()

void SOH_MonitorShutDownTimer ( uint32  counterValue)

This function is called only by Runnable_SOH_Timing(), after having read the OsCounter. Here, that counter value is used to update the time windows of the detectors that adopt the Time Window Filter.

[$SDD_SOH 034]

If the previous counter value has not been initialized (is 0 or lower than the current counter value), it assumes the current counter value, so the time elapsed will result lower than 1s and the time window will not be updated.

[$Satisfies $SRS_SOH 025]
[$SDD_SOH 018]

If a detector adopts the Time Window filter, the field SOH_Filter in its SOH_DetectorType instance is equal to SOH_TWFiltering.

[$Satisfies $SRS_SOH 014]
[$SDD_SOH 019]

If field SOH_Cntr in the detector's SOH_DetectorType instance is different from 0, it means (at least) the first error occurrence is detected. For a detector that adopts the Time Window filter, if the first error occurrence is detected, the field SOH_TW in the detector's SOH_DetectorType instance can be incremented (if time elapsed is greater than 1s). The field SOH_TW implements the time window for the relative detector.

[$Satisfies $SRS_SOH 014]
[$Satisfies $SRS_SOH 017]

If field SOH_TW reaches the relative threshold in field SOH_TWThreshold:

[$SDD_SOH 029]
  • SOH_Cntr goes to 0
    [$Satisfies $SRS_SOH 016]
    [$SDD_SOH 030]
  • SOH_TW goes to 0.
    [$Satisfies $SRS_SOH 016]

This function is called only by Runnable_SOH_Timing() and ShutdownNotificationToSoh(), after having read the OsCounter. Here, that counter value is used to update SUM_SOH_ShutDown_Timer of the Shutdown Delay Detector.

[$SDD_SOH 035]

If the previous counter value has not been initialized yet, it assumes the current counter value.

[$Satisfies $SRS_SOH 027]
[$SDD_SOH 036]

Otherwise, the difference between the two values is converted in seconds and the previous counter value is incremented by a number of ticks equal to 1s till the difference stops being greater than 1s.

[$Satisfies $SRS_SOH 027]
[$SDD_SOH 031]

If a shutdown has been detected by the Main Runnable, the IRV ShutdownTimerFlag is TRUE.

[$Satisfies $SRS_SOH 005]
[$SDD_SOH 032]

If SUM_SOH_ShutDown_Timer reaches SUM_SOH_ShutDown_Timer_Thresh, SOH_Event_Detector() is called to increment SOH_Event_Detector and to call the respective filter.

[$Satisfies $SRS_SOH 024]

◆ SOH_Write()

Std_ReturnType SOH_Write ( SOH_DetectorType const *  item)

This function is called only by SOH_Event_Detector(), after having increase the field SOH_Cntr in a detector's SOH_DetectorType instance. Here, that detector goes under the operations of its related filter using that new value of SOH_Cntr.

If field SOH_Cntr reaches its threshold count calibration in field SOH_CntrThreshold():

[$SDD_SOH 020]
  • increments field SOH_DIDCntr, if SOH_DIDCntr has not reached 0xFFFE yet
    [$Satisfies $SRS_SOH 015]
    [$Satisfies $SRS_SOH 018]
    [$SDD_SOH 021]
  • resets field SOH_Cntr to 0
    [$Satisfies $SRS_SOH 015]
    [$SDD_SOH 022]
  • resets field SOH_TW to 0.
    [$Satisfies $SRS_SOH 015]
