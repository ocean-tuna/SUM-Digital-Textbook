◆ ShutdownNotificationToSoh()

void ShutdownNotificationToSoh ( void  )

This function is a callback used only once: in the BswM shutdown action list. Its scope is only to call SOH_MonitorShutDownTimer(), that updates SUM_SOH_ShutDown_Timer if SOH is monitoring a shutdown delay.

The Time Manager Runnable is the only other function that calls SOH_MonitorShutDownTimer(), so the only other one that could ask to update SUM_SOH_ShutDown_Timer. But, once the shutdown action list starts, all the runnables will not be scheduled anymore.

[$SDD_SOH 028]

So, during this callback, SUM_SOH_ShutDown_Timer will be updated for the last time.

[$Satisfies $SRS_SOH 006]

◆ SOH_CheckMEC()

static boolean SOH_CheckMEC ( void  )
static

This function is called only by Runnable_SOH_Main() in order to perform the initial checks/activities of the Shutdown Detector.

A shutdown is detected if both conditions are present:

[$SDD_SOH 023]
  • port PNC_SUSD_ShutdownPermission says all the Partial Networks are deactivated, so its value is 0xFF
    [$Satisfies $SRS_SOH 005]
    [$SDD_SOH 024]
  • port SUSD_SOH_PermitExecution has the ECU shutdown target bit (bit 1) equals to 0.
    [$Satisfies $SRS_SOH 005]
[$SDD_SOH 027]

If a shutdown is detected, the flag ShutdownTimerFlag becomes TRUE, so SUM_SOH_ShutDown_Timer can be incremented by the Time Manager Runnable.

[$Satisfies $SRS_SOH 005]
[$SDD_SOH 025]

A shutdown is aborted if a wakeup event occurs, so if port SUSD_SOH_PermitExecution has the LSB bit equals to 1.

[$Satisfies $SRS_SOH 007]
[$SDD_SOH 026]

If a shutdown is aborted, SUM_SOH_ShutDown_Timer is cleared.

[$Satisfies $SRS_SOH 023]
