\chapter{Contact, Support and Problem Reporting}
\section{Technical Support}
Technical support is available to all RTA users with a valid support contract. If you do not have a valid support contract, please contact your regional sales office (see below).
\vfill
The best way to get technical support is by email. Any problems or questions about the use of the product should be sent to: 
\begin{itemize}
	\item \href{rta.hotline@etas.com}{rta.hotline@etas.com}	
\end{itemize}    

If you prefer to discuss your problem with the technical support team, you can all the support hotline on: 
\vfill
 +44 (0)1904 562624. 
\vfill
The hotline is available during normal office hours (0900-1730 GMT/BST)
\vfill
In either case, it is helpful if you can provide any of the following relevant information when contacting technical support:
\begin{itemize}
	\item Your support contract number
	\item The version(s) of the ETAS tool(s) you are using
	\item The error messages or return codes you received (if any)
	\item The operation that resulted in the error
\end{itemize}
